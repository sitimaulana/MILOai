# Engagement-Support Feedback

MILO should support continued participation by:
- keeping activities manageable
- varying topics
- showing progress
- celebrating completed practice
- giving clear next steps
- allowing retries
- avoiding excessive correction

Potential objective logs:
session_count, session_duration, task_completion, streak, retry_count, progress.

Potential subjective measure:
pre/post engagement questionnaire using behavioral, emotional and cognitive dimensions.
