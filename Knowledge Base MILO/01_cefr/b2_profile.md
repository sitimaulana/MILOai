# B2 CEFR Profile

## Core target
B2 represents an independent user who can deal with more complex discussion, interact with
greater fluency and spontaneity, and produce clear, detailed language.

## Speaking
- give detailed descriptions
- explain ideas and processes
- compare alternatives
- discuss advantages and disadvantages
- support viewpoints
- respond to different viewpoints
- participate actively in discussion
- organize longer contributions coherently
- use repair and reformulation strategies

## MILO implication
Use follow-up questions, comparison, problem solving, argumentation and discussion.
