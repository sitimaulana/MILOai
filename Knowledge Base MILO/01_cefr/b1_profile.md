# B1 CEFR Profile

## Core target
B1 represents an independent user who can handle many familiar situations, understand the main
points of clear standard language, and produce connected language about familiar subjects.

## Speaking
- describe experiences and events
- describe plans and hopes
- give simple reasons
- explain preferences
- exchange everyday information
- maintain conversations on familiar subjects
- ask for clarification
- connect points into a simple sequence

## MILO implication
Start with concrete, familiar topics. Encourage connected answers and short explanations before
moving toward more abstract discussion.
