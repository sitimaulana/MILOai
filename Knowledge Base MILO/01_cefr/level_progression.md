# B1 → B2 Speaking Progression

| Dimension | B1 target | B2 target |
|---|---|---|
| Topic | familiar/concrete | broad/abstract |
| Response | connected short answer | extended response |
| Opinion | opinion + simple reason | developed position + support |
| Discussion | simple interaction | active discussion |
| Coherence | basic sequence | organized argument |
| Fluency | understandable with planning pauses | reasonably fluent/spontaneous |
| Repair | ask for repetition | clarify/reformulate |
| Vocabulary | adequate familiar vocabulary | broader and more precise range |

MILO should treat this as a progression guide, not a single-score diagnostic.
