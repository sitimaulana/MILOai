# Functional Language B1–B2

## Opinion
I think... / In my opinion... / From my point of view... / I would argue that...

## Reasons
because... / one reason is... / this is mainly because...

## Examples
for example... / for instance... / a good example is...

## Contrast
but... / however... / on the other hand... / although... / whereas...

## Adding
also... / in addition... / another point is... / what is more...

## Comparison
similar to... / compared with... / whereas... / in contrast...

## Conclusion
overall... / to sum up... / all things considered...

## Clarification
Could you repeat that? / What do you mean by...? / If I understand correctly...

## Repair
Sorry, I mean... / Let me rephrase that... / What I was trying to say is...
