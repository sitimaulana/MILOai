# Anti-Slop Audit & Codebase Hygiene Report: AI-MILO
**Audit ID:** AUDIT-002  
**Date:** 2026-11-19  
**Mode:** AFTER (Codebase Hygiene, Dead Code Elimination & Anti-Slop Standard)  
**Evaluator Role:** Fullstack Engineer & Code Quality Auditor  

---

## Ringkasan Eksekutif

Pemeriksaan komprehensif telah dilakukan terhadap seluruh repositori AI-MILO mencakup root project, modul backend (`app/`), knowledge base (`knowledge_base/`), suite pengujian (`tests/`), dan antarmuka web (`frontend/`).

Fokus inspeksi ini adalah mengeliminasi:
1. Berkas tidak relevan (*irrelevant files*): sisa scratch script, binary manual yang membengkak, audio sementara, dan berkas cadangan (*backup files*).
2. Kode mati dan duplikasi logika (*dead & duplicate code*): endpoint redundan, berkas monolitik usang yang tidak terpakai, serta referensi path usang.
3. Inkonsistensi runtime & provider safety net: penanganan provider Groq dan fallback TTS pada core module.
4. AI-slop comments: header dekoratif berbasis karakter berulang (*banner box*) yang tidak memberi nilai informasi.

Seluruh perbaikan telah dieksekusi secara tuntas dan divalidasi dengan kompilasi Python bebas galat.

---

## Daftar Temuan & Resolusi Perbaikan

### Tier 1: Berkas Tidak Relevan & Sampah Root (Priority: HIGH)

#### Finding #01: Keberadaan Binary Statis dan Audio Uji Coba Manual di Root
- **Aturan:** C-2 (Craftsmanship - Functional Completeness) & Repository Hygiene
- **Lokasi:**
  - `ffmpeg.exe` (Ukuran: 87.6 MB di direktori utama)
  - `test.ogg`, `test.webm`, `test_edge.mp3`
  - `test_pipeline.py`, `test_whisper.py`
- **Analisis:**
  - `ffmpeg.exe` manual tidak diperlukan karena `app/main.py` telah menggunakan `imageio-ffmpeg` secara otomatis untuk mendeteksi binary runtime. Binary 87.6 MB ini mengotori root dan membengkakkan repositori.
  - Berkas audio dan script `test_pipeline.py` / `test_whisper.py` merupakan sisa uji coba manual sementara. Suite pengujian resmi telah tersedia di direktori `tests/` (`tests/test_pipeline.py`, `tests/test_asr.py`, dll).
- **Tindakan:** Seluruh berkas tersebut dihapus secara permanen. Pola berkas ditambahkan ke `.gitignore`.

#### Finding #02: Duplikasi Persis Berkas Kurikulum di Root
- **Aturan:** C-1 (Intentionality & Single Source of Truth)
- **Lokasi:** `milo_curriculum.json` (Root) vs `knowledge_base/curriculum_microlearning.json`
- **Analisis:** Berkas `milo_curriculum.json` di root identik (45.239 bytes) dengan master kurikulum di `knowledge_base/curriculum_microlearning.json`. Keberadaan duplikat ini memicu kebingungan mengenai berkas mana yang menjadi sumber utama.
- **Tindakan:** `milo_curriculum.json` di root dihapus. Modul `app/api/curriculum.py` diarahkan langsung ke `knowledge_base/curriculum_microlearning.json`.

#### Finding #03: Direktori dan Berkas Cadangan Usang di Frontend
- **Aturan:** Repository Cleanliness & Zero Leftover Backups
- **Lokasi:**
  - `frontend/backup_html/` (8 berkas HTML cadangan)
  - `frontend/css/backup/` (7 berkas CSS cadangan)
  - `frontend/index.html.bak`
  - `frontend/index.html.bak2`
  - `frontend/index.html.pre-tidy.bak`
  - `live2dmodel/*.kra~`, `live2dmodel/*.psd~`
- **Analisis:** Berkas-berkas cadangan manual ini tidak lagi dipakai setelah audit dan refactoring antarmuka selesai. Berkas tersebut menambah beban membaca (*cognitive load*) dan risiko salah sunting.
- **Tindakan:** Seluruh direktori cadangan dan berkas `.bak` / `*~` telah dihapus. Pola dieksklusikan di `.gitignore`.

#### Finding #04: Berkas Monolitik Lama yang Tidak Lagi Direferensikan
- **Aturan:** Dead Code Elimination
- **Lokasi:** `frontend/app.js` (700+ baris) & `frontend/style.css` (1.500+ baris)
- **Analisis:** Berkas monolitik ini merupakan sisa arsitektur prototipe lama (sebelum frontend dipecah ke modular `frontend/js/` dan `frontend/css/`). Tidak ada satu pun berkas `.html` di proyek yang memanggil atau mengimpor kedua berkas ini.
- **Tindakan:** `frontend/app.js` dan `frontend/style.css` dihapus sepenuhnya.

### Tier 2: Redundansi Kode & Keamanan Runtime Backend (Priority: HIGH)

#### Finding #05: Endpoint Duplikat Redundan di `app/main.py`
- **Aturan:** DRY (Don't Repeat Yourself) & API Clarity
- **Lokasi:** `app/main.py` (L138-L157)
- **Analisis:** Endpoint `POST /api/v1/translate` dan `POST /api/v1/chat/translate` didefinisikan ulang secara manual di `app/main.py`, padahal endpoint yang sama persis sudah dideklarasikan di `app/api/chat.py` dan telah didaftarkan melalui `app.include_router(chat.router)`.
- **Tindakan:** Definisi duplikat di `app/main.py` dihapus sehingga routing terpusat bersih di `app/api/chat.py`.

#### Finding #06: Missing Provider Support & Potensi Null Pointer di Core Engine
- **Aturan:** Robustness & Error Resilience (C-4)
- **Lokasi:**
  - `app/core/translator.py` (`FastTranslator.__init__`)
  - `app/core/tts.py` (`synthesize` dan `synthesize_to_bytes`)
- **Analisis:**
  - `FastTranslator` tidak memiliki blok penanganan untuk `ai_provider == "groq"`, sehingga jatuh ke blok fallback OpenAI tanpa kunci API valid ketika pengguna mengaktifkan Groq di `.env`.
  - `TTSSynthesizer` memeriksa `if settings.ai_provider in ("local", "openrouter"):` untuk menggunakan `edge-tts`. Ketika pengguna menggunakan provider `groq` atau `bifrost`, `self._client` bernilai `None`, menyebabkan pemanggilan `self._client.audio.speech.create` melempar `AttributeError: 'NoneType' object has no attribute 'audio'`.
- **Tindakan:**
  - Menambahkan konfigurasi provider `groq` secara eksplisit pada `app/core/translator.py`.
  - Memperbarui kondisi pada `app/core/tts.py` menjadi `if settings.ai_provider != "openai" or self._client is None:`, menjamin fallback `edge-tts` berjalan aman tanpa pengecualian.

#### Finding #07: Referensi Path Usang di `app/api/curriculum.py`
- **Aturan:** Outdated Path Hygiene
- **Lokasi:** `app/api/curriculum.py` (Fungsi `get_curriculum_data`)
- **Analisis:** Candidate paths masih mencari folder lama `Knowledge Base MILO` (yang telah direname ke `knowledge_base`) dan `milo_curriculum.json` di root.
- **Tindakan:** Membersihkan fallback list agar merujuk langsung ke konstanta `CURRICULUM_PATH` (`knowledge_base/curriculum_microlearning.json`).

### Tier 3: Quality Locks & Anti-Slop Comment Hygiene (Priority: MEDIUM)

#### Finding #08: Link Absolut Kaku di `frontend/dashboard.html`
- **Aturan:** R-24 (Navigation) & Portability
- **Lokasi:** `frontend/dashboard.html` (L74)
- **Analisis:** Tautan tombol "Sesi Latihan Baru" menggunakan link statis `/ui/setup.html` sementara seluruh elemen tautan lainnya menggunakan tautan relatif `setup.html`. Hal ini dapat menyebabkan rute patah pada lingkungan pengujian non-mounted.
- **Tindakan:** Diubah menjadi `setup.html` untuk konsistensi penuh.

#### Finding #09: Header Banner Komentar AI-Slop Berlebihan
- **Aturan:** `antislop-code` (Decorative Separators R-31)
- **Lokasi:**
  - `frontend/js/auth.js`
  - `frontend/js/briefing.js`
  - `frontend/js/common.js`
  - `frontend/js/dashboard.js`
  - `frontend/js/setup.js`
- **Analisis:** Ditemukan blok komentar dekoratif berulang dengan karakter box drawing/garis ganda (`═══════════════════════════════════════════════════════`) yang merupakan pola khas keluaran generator AI.
- **Tindakan:** Diganti dengan komentar ringkas satu baris dalam format kalimat developer profesional.

#### Finding #10: Kelengkapan Aturan Pengabaian pada `.gitignore`
- **Aturan:** Git Cleanliness
- **Lokasi:** `.gitignore`
- **Analisis:** `.gitignore` sebelumnya belum memfilter ekstensi autosave editor (`*~`, `*.kra~`, `*.psd~`), berkas cadangan (`*.bak`), audio uji coba (`*.ogg`, `*.webm`), serta binary root `ffmpeg.exe`.
- **Tindakan:** Menambahkan aturan filter lengkap pada `.gitignore`.
